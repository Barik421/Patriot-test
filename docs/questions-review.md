# Тест на патріота — 120 запитань для перевірки

Усі запитання та варіанти відповідей у змішаному редакційному порядку. У самому тесті відповіді перемішуються ще раз для кожної сесії. Літери не відповідають типажам.

Для правок можна посилатися на номер запитання та літеру відповіді. Редакція 2.
