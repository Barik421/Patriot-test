# Оцінки відповідей

0 — патріотична / конструктивна реакція; 1 — прагматична; 2 — песимістична; 3 — тотальне знецінення. Бали редакційні й відкриті для перегляду.

За 15 питань: 0–11 — Патріот, 12–22 — Недопатріот, 23–33 — Недозрадойоб, 34–45 — Зрадойоб. Відсоток — позиція на шкалі зради: сума / 45 × 100.
